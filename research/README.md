## Classification fields

Each reference should ideally answer:

| Field | Meaning |
|---|---|
| Physical mice | How many separate mouse devices are used? |
| Independent cursors | Are separate moving pointers maintained? |
| Users | One user with two hands, or multiple users? |
| Scope | Game, research, library, desktop tool, patent, etc. |
| Verification | Primary source checked, secondary source, or lead only? |

## Important distinction

A project can be called “dual mouse” without being “dual cursor.” For example, one mouse may move a single cursor while another mouse is used only for tapping. Conversely, software can display multiple cursors without using multiple physical mice.

Dual Mouse Lab tracks these separately.
