# Contributing

Dual Mouse Lab accepts research references, corrections, prototype improvements, and small interaction demos.

## Adding a reference

Please include:

- title
- author / developer / organization
- year or release date when known
- category
- canonical or primary URL
- short neutral summary
- why it matters to dual-mouse / dual-cursor interaction
- physical mouse count
- independent cursor count
- number of users
- verification status

Prefer primary sources: official documentation, project pages, papers, repositories, store pages, and patent databases.

Do not copy large sections of copyrighted material. Summarize and link instead.

## Adding code

- Keep prototypes small and reproducible.
- Document OS and toolchain requirements.
- Avoid dependencies unless they provide a clear benefit.
- Clearly separate device input, pointer state, and demo logic.
- Do not claim OS-wide multi-cursor support when a prototype only draws virtual cursors inside its own window.

## Corrections

If a reference is inaccurate or misclassified, open an issue with a primary source and the proposed correction.
