# Dual Mouse Lab

> **물리 마우스 두 개, 독립 커서 두 개, 양손 인터랙션**을 연구하고 실험하는 저장소입니다.

[English README](README.md)

## 핵심 아이디어

일반적인 데스크톱 환경에서는 여러 마우스를 연결해도 입력이 하나의 시스템 커서로 합쳐집니다. Dual Mouse Lab은 다음과 같은 구조를 탐구합니다.

```text
왼손  -> 물리 마우스 A -> 커서 A
오른손 -> 물리 마우스 B -> 커서 B
```

두 커서는 각각 독립적으로 이동하고, 클릭하고, 드래그하고, 휠과 추가 버튼을 사용할 수 있어야 합니다.

이 저장소는 완성형 게임 하나를 만드는 프로젝트가 아닙니다. **“마우스 두 개를 각각 하나의 손처럼 쓰면 무엇을 만들 수 있을까?”**라는 생각을 가진 사람들이 관련 자료를 찾고 실제 구현까지 시작할 수 있는 **백과사전형 자료 저장소 + 프로토타입 실험실**을 목표로 합니다.

## 프로젝트 목표

1. **선행사례와 자료 수집**
   - 게임과 플레이 가능한 실험
   - 논문과 HCI 연구
   - API, 라이브러리, 게임 엔진 플러그인, 데스크톱 도구
   - 특허와 역사적 사례
   - 영상과 개발자 기록

2. **최소 참조 구현 제작**
   - 연결된 물리 마우스 열거
   - 어느 장치가 이벤트를 발생시켰는지 구분
   - 한 프로그램 창 안에서 두 개의 독립 가상 커서 렌더링
   - 클릭 / 우클릭 / 휠 / 드래그 / 장치 연결·해제 / 마우스별 설정

3. **듀얼 포인터 인터랙션 연구**
   - 대칭/비대칭 양손 작업
   - 두 커서 사이 거리, 각도, 중점, 교차, 상대속도
   - 두 커서를 동시에 추적할 때의 시각적 주의 문제
   - 왼손 학습과 마우스별 감도 차이

4. **작은 데모 제작**
   - 리듬 / 협응
   - 조준 / 슈팅
   - 두 점으로 물체 잡기
   - 물리 / 로프 / 연결선 기반 인터랙션

## 어디부터 시작하나요?

처음부터 Windows 전체에 네이티브 시스템 커서 두 개를 만드는 것이 목표는 아닙니다.

우선 다음을 검증합니다.

```text
Mouse A --\
          -> 장치별 입력 -> Cursor A 상태 -> 프로그램 창에 렌더링
Mouse B --/             -> Cursor B 상태 -> 프로그램 창에 렌더링
```

Windows Raw Input은 같은 종류의 입력장치라도 입력 출처를 구분할 수 있으므로, 이 구조만으로도 핵심 아이디어를 검증할 수 있습니다.

## 개발 순서

```text
00  관련 자료 아카이브
01  물리 마우스 장치 검사기
02  독립 가상 커서 두 개
03  클릭 / 휠 / 드래그
04  커서 UI와 장치별 설정
05  양손 인터랙션 프리미티브
06  작은 플레이 가능한 데모
07  선택적으로 OS 전체 멀티커서 실험
```

자세한 내용은 [ROADMAP.md](ROADMAP.md)를 참고하세요.

## 선행사례에 대한 입장

듀얼 마우스와 멀티커서는 새로운 기술 발명이 아닙니다. 과거 HCI 연구, 멀티유저 시스템, ManyMouse 같은 라이브러리, MouseMux 같은 데스크톱 도구, 그리고 DualOperation·2 Mouse 4 U·Shatterball·Turnip Mountain 같은 최근 사례가 존재합니다.

따라서 이 프로젝트는 **“세계 최초의 두 번째 마우스”를 주장하지 않습니다.** 대신 아직 정리되지 않은 자료를 모으고, **한 명의 사용자가 두 손으로 두 포인터를 조작하는 방식**을 더 쉽게 재현하고 실험하는 것을 목표로 합니다.

## 현재 상태

비공개 초기 구축 단계입니다. API, 출처, 프로토타입을 실제 장치에서 검증한 뒤 공개 저장소로 전환하는 것을 목표로 합니다.

## 아이디어의 출발점

처음 아이디어는 한 컴퓨터에 마우스 두 개를 연결하면 커서도 두 개가 되고, 양손으로 각각 클릭·드래그하면서 게임이나 새로운 인터랙션을 만들 수 있지 않을까 하는 질문에서 시작했습니다. 이 저장소는 그 아이디어를 자료 아카이브와 재사용 가능한 실험 환경으로 확장합니다.
