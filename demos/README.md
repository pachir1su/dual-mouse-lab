# Demos

This directory is for **small playable interaction experiments**, not a full commercial game.

Each demo should answer one focused question, such as:

- Can a player comfortably track two moving cursors?
- Is cursor-to-cursor distance a useful continuous game input?
- Does two-point grabbing feel natural with two mice?
- Can a dual-cursor rhythm mechanic be learned quickly?
- Does assigning different roles to each hand work better than symmetric roles?

## Candidate demos

### Two-point manipulation

Grab an object's two handles with both cursors and move, rotate, or resize it.

### Rhythm / coordination

Notes require separate cursor trajectories or two-cursor relationships such as crossing, spreading, rotation, and synchronized clicks.

### Targeting

Two reticles independently acquire targets. Useful as a simple stress test, not intended as the final project identity.

### Tether physics

The segment between Cursor A and Cursor B becomes a rope, laser, shield, cutting line, or elastic constraint.
